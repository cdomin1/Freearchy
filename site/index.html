Everything installed. Nothing to configure.

Keyboard-driven tiling

vellum-wm — a Rust tiling WM on penrose/x11rb. Omarchy keymap, workspaces 1–9, gaps, themed borders. No mouse required.

Animated X11

picom 13 animates window open, close and tiling moves, with rounded corners and soft shadows. Runs on a plain framebuffer — works in VMs, no KMS handshake.

22 themes

Every Omarchy palette ported. One command re-themes the terminal, launcher, panel, borders and wallpaper.

Power that thinks

AC/battery profiles via devd, adaptive CPU with powerdxx, ThinkPad charge thresholds, S3/s2idle suspend that locks before it sleeps. Lid, sleep button and zzz all covered.

GPU autodetect

Intel, AMD & NVIDIA — including hybrids and five driver generations. The boot GPU drives the desktop, prime-run hands work to the dGPU.

Inline installer

An Omarchy-style guided wizard: keymap → disk → ZFS → user → done. Live logs to /var/log, unattended installs via a config file, first-boot setup.

Connectivity

vellum wifi scans and joins networks; vellum bt drives the netgraph Bluetooth stack — scan, PIN pair, connect. Experimental, like the platform they ride on.

Scratchpad & menus

Super+S drops a floating terminal on any workspace. Super+Alt+Space opens rofi menus for system, theme, power, capture, network and Bluetooth.

ArtCraft

Storytold's AI studio builds on FreeBSD via scripts/install-artcraft.sh — the pure-Rust egui app, no Tauri. Experimental, bundled by build script.

Why FreeBSD?

ZFS root with bectl boot environments — the snapshot-and-rollback story, natively. A coherent base system instead of a kernel plus thirty vendors. Jails when you want isolation. Ports when you want the source.

Same contract as Omarchy: one command, a fully-working, opinionated desktop. Just on a different kernel.
